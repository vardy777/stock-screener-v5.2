# V5.2 Product Specification

V5.2 is a standalone after-close A-share Alpha Research and Swing Candidate
Engine. It will use only facts legally available by D close to reconstruct the
eligible universe, calculate deterministic features and produce nested
Watchlist 50 / Top 20 / Top 10 / Top 5 rankings for 1-5 session evaluation.

Phase 0 establishes independence only. Historical PIT data, features, labels,
ranking and alpha evaluation are not yet implemented. An eventual AlphaScore is
an explainable score, not a probability. The project may conclude
`ALPHA NOT FOUND`.

Realtime full-market scanning, old product time choreography, notification,
scheduling, live brokers, automatic orders, production capital, ML-first work,
news/social sentiment, tick/Level-2 data and complex optimization are excluded.
`research_locked=true`; broker orders are disabled.
