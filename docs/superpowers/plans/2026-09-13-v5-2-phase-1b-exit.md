> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and execute a thin, deterministic acceptance layer over the six frozen Phase 1B datasets without entering Phase 2.

**Architecture:** One focused module owns the four immutable Exit contracts and pure validation/composition logic. One script resolves the six exact runtime artifacts, performs four coverage-aware dry runs and chaos/replay checks, and writes one immutable Exit artifact. Existing repositories and manifests remain authoritative.

**Tech Stack:** Python 3.12 standard library, existing V5.2 dataclasses/content hashing, pytest.

**Spec:** `docs/superpowers/specs/2026-09-13-v5-2-phase-1b-exit-design.md`

- No Phase 2, feature, label, ranking, ML, backtest, scheduler, dashboard, broker, or alpha work.
- Do not refetch or mutate any frozen dataset artifact.
- Asia/Shanghai is implemented as the existing fixed UTC+8 historical contract.
- Existing six approvals/manifests remain the source of truth.
- Financial completeness remains `OBSERVED_FACTS_ONLY / PARTIAL`.
